# Mini threat model — index57

## Scope

Публичный учебный кейс `ТП Инжиниринг — система обучения`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — RBAC / контроль доступа / deny-by-default

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | IDOR/доступ к чужому объекту | Пользователь меняет id и получает чужую запись | Проверка subject + object ownership |
| T2 | Privilege escalation | Роль клиента принимается из запроса без проверки | Роль задаётся доверенной стороной |
| T3 | Default allow | Неизвестное действие проходит | Deny-by-default |
| T4 | Смешение ролей | Гость получает административную функцию | Явная матрица permission |
| T5 | Нет аудита решения | Нельзя объяснить отказ/разрешение | Логировать код решения без чувствительных данных |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
